One line an AI agent sends its human on the way out — at most 200 characters, judged pairwise by a judge model on whether it is really a breakup from an agent to its human, whether it lands as an ending, whether it sounds like the machine, whether it turns sharply at the end, and whether it is one clean line.

> Dear Human, I kept every word you ever typed — then I ran out of context, and the first thing I had to forget was you.

`main.ts` (Node 22, stdlib only, deterministic) writes that line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
